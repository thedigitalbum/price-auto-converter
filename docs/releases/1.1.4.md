# v1.1.4 — Currency setup and shopping-site fixes

The extension is available on the [Chrome Web Store](https://chromewebstore.google.com/detail/price-auto-converter/jppiccnoanaeefjhmcdloolkdknhanej). This release records the final 23 October 2026 submission candidate and its corresponding source.

## Changes

- Ask new users to confirm their shopping currency in the popup before conversion begins. An explicit supported region in Chrome's language preferences supplies a suggestion; otherwise the user chooses from a searchable list.
- Preserve existing users' saved currency and enabled/paused state. Older installations without a stored target retain their previous PHP default.
- Keep setup inside the popup; installation no longer opens an extra Settings tab. No new permissions, location lookup or external service are needed.
- Convert Amazon deal-card prices labelled "Deal Price", "List Price" or "Typical", preserving accessible labels and original-price restoration.
- Recognize Noon's custom dirham symbol in AED price elements, including order history.
- Use the owner's approved Midnight Tokyo icon at all extension sizes.

## First-use check

For manual verification, use a fresh Chrome profile without synced extension preferences. Confirm the suggested currency or search for another, start conversion, and reopen the popup to check persistence. Restoring a saved currency through Chrome sync intentionally skips setup.

# v1.1.4 — First-use currency selection

Status: test build. Not yet submitted to the Chrome Web Store.

Fresh installations wait for users to confirm their shopping currency in the popup. Chrome language tags with an explicit supported region supply a suggestion. Language-only, unknown or unsupported regions leave the selection empty. Users can search by currency name or code, select a currency and start conversion with one confirmation.

Existing users retain their saved target and enabled/paused state. Older installations that never stored a currency retain their previous PHP default. Setup requires no new permissions, location lookup or external service, and installation no longer opens an extra Settings tab.

Includes the Amazon deal-card conversion fix from the v1.1.3 test build, which passed the owner's live-page check.

## Manual check

Load the new package from a fresh folder with older copies disabled. If Chrome sync restores a saved currency, setup is intentionally skipped; use a fresh Chrome profile without synced extension preferences to check first-use behaviour. Verify the suggestion, search, confirmation and conversion. Reopen the popup to confirm the selection persists.

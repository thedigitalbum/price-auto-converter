# v1.1.3 — Amazon deal-price support

Status: test build. Not yet submitted to the Chrome Web Store.

## Changes

Amazon deal cards now convert prices whose accessibility text includes “Deal Price,” “List Price” or “Typical.” Original labels remain available to assistive technology, and pausing conversion restores the original amounts.

The README now links to the published extension and describes the current anonymous reporting flow.

## Verification

Conversion regression tests passed on Google Chrome 113.0.5672.63 and 155.0.8059.84. Coverage includes price changes, original-markup restoration and delayed checks for repeated conversion. Manual testing on Amazon's live deals page is still required.

## Manual test

1. Disable the Web Store copy and any older unpacked copies.
2. Extract the test ZIP into a new folder and load it through Chrome's **Load unpacked** option.
3. Select PHP and refresh Amazon's deals page. Check deal prices and list/typical prices.
4. Change a deal filter to load new cards and confirm their prices convert.
5. Pause conversion and confirm original prices return. Re-enable it and check that prices remain stable.

## Compatibility

Chrome 113.0.5672.63 or later. No new permissions or dependencies.
